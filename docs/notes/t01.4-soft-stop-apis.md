# 软停止路径留档（T01.4）

- 日期：2026-08-11
- 目标：优先用 API 停推演，**避免杀进程**

## 找到的软停止 API

| API | 位置 | 行为 |
|---|---|---|
| `Game.Pause()` | `Command_Core/Game.cs` | `__SimRunStatus = Paused`；触发 `CurrentGameStatusChanged` |
| `Game.Run()` | 同上 | 仅置 `Running`（不推进脉冲） |
| `LUA_VP_PauseSimulation` | `LuaSandBox.cs` | 调 `ScenarioContext.GameContext.Pause()` |
| `LUA_VP_RunSimulation` | 同上 | 调 `GameContext.Run()` |
| `ClientCore.BW_Core_Pulse.CancelAsync()` | `ClientCore.ShutdownCleanup` / Initialize 创建的 BackgroundWorker | GUI 连续脉冲后台任务取消（`WorkerSupportsCancellation=true`） |
| 协作取消 | PoC 脉冲循环 | 在两次 `Advance1Pulse` 之间检查取消标志并 `Pause()` + `break` |

## 本轮采用
T01.3 步进模型是同步 `Advance1Pulse` 循环，因此软停 = **`Game.Pause()` + 循环退出**（必要时再 `BW_Core_Pulse.CancelAsync`）。  
不杀 `F1`/`F1-Console`/PoC 进程来“停止推演”；PoC 正常 `Environment.Exit(0)` 退出。

## 判定
若实测无法在不杀进程的情况下停住并恢复可保存/编辑 → **立即上报 M3 阻塞**，停止后续 T01.4 扩张。
