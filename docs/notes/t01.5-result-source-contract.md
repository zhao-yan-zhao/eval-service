## 唯一权威数据源

**CSV（`EventExporter_CSV`）** —— 不是 SQLite。

| 候选 | 是否权威 | 理由 |
|---|---|---|
| **CSV** | **是（唯一）** | PRD 明确要求读「事件导出 CSV」；本机生产目录 `EventExport/*/EventExport_CSV/*.csv` 已广泛使用；字段含 `TimelineID` |
| SQLite（`EventExporter_Sqlite`） | 否 | 源码存在且可并行启用，但是**可选旁路**；PRD 未将其定为验收合同；本 PoC **显式关闭** |

不允许「哪个顺手用哪个」。产品 `result.read` 只认 CSV。

## 目录与命名（实测）

- 根：`EventExporterManager.ExportDir`（默认可写根下 `EventExport`；PoC 可指向隔离目录）
- 相对路径：`{ExportDir}/{场景名}/EventExport_CSV/{时间前缀}_{事件类型}.csv`
- 时间前缀：`GetFileNameTimePrefix()` = `yyyy-M-d_H.m.s`
- 首列：`TimelineID`（与 `Scenario.TimelineID` 一致）

## 「推演完成」信号（必须同时满足）

1. **仿真完成**：请求的脉冲已跑完，且 `Game.Pause()` 后 `Game.Status == Paused`  
   （日志：`SIM_COMPLETE_SIGNAL:requested_steps_done_and_Game.Pause`）
2. **导出完成**：`EventExporter_CSV.QueueLength == 0`（Pause 后轮询至空）  
   （日志：`EXPORT_COMPLETE_SIGNAL:CsvExporter.QueueLength==0_after_Pause`）
3. 读文件前：`EnableCsvExport(false)` 关闭写入句柄（否则 CSV 可能被占用）

自然终局场景另可用 `Scenario.HasEnded` / `ScenEdit_EndScenario`，但本 PoC 步进模型以 (1)(2) 为准。

## 区分本次 vs 历史运行

1. 每次运行分配唯一 `Scenario.TimelineID`（= run_id）
2. 读取时只统计 `TimelineID == 本次 run_id` 的行
3. 推荐再加**每次独立 export 子目录**，避免文件混写

## 最小指标（本 PoC）

- `METRIC_EVENT_ROWS_THIS_RUN`：本 TimelineID 事件行数（>0）
- `METRIC_EVENT_ROWS_OTHER_RUN`：必须为 0
- `CSV_FILE_COUNT`：本次导出目录下 CSV 数
