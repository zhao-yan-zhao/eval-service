# F1 AI 助手测试计划

> **准绳 PRD**：`F1-AI助手-PRD-v1.3.md`。编排为 C# 原生状态机；知识为静态版本化知识包（见 ADR `002-technology-selection.md`）。

## 框架、目录与自动化边界
- 首先执行 `TASKS.md` 的 T00 确定测试框架；没有既有约定时推荐 **xUnit + Microsoft.NET.Test.Sdk**，用于 `.NET 5` 纯逻辑测试。最终选择以 T00 ADR 为准（已选 xUnit）。
- 建议目录：`tests/F1.AiAssistant.Tests/`（**原生状态机**、Schema、迁移、SSE mock、**知识包 manifest**）、`tests/F1.AiAssistant.IntegrationTests/`（临时文件/SQLite/知识包加载）、`tests/F1.AiAssistant.Smoke/`（受控 F1 场景）。
- 自动化边界：自动运行模型 SSE fake server、工具参数拒绝、迁移/备份/脱敏/结果解析、状态机转移与限额、知识包校验；真实 F1 GUI、推演内核、外网模型和许可证依赖放专机受控冒烟并保留日志/录屏。
- Mock 边界：编排层只依赖 `IF1AutomationFacade`（及只读 `IKnowledgeSource` fake）；fake 可模拟步骤、超时、取消与结果，从而不让单元测试直连 `ClientCore`。**不**引入 LangGraph/SK 测试替身作为 V1 路径。

## 测试分层
1. **单元测试**：原生状态机转移、轮次/时间/重试上限、上下文摘要裁剪、工具 Schema、Lua 策略、密钥脱敏、备份保留清理、场景指纹、知识包 manifest 解析与版本兼容判定。
2. **集成测试**：SQLite 初始化与迁移、DPAPI、本地原子备份、模拟 SSE（文本/工具调用/429/畸形分段）、DB3K 只读查询、CSV 大文件流式聚合、知识包目录加载。
3. **F1 PoC 与冒烟**：真实场景读取、受控 Lua 变更、保存重载、步进运行、停止、导出读取、回滚；每项连续三次。
4. **端到端测试**：本地模型、DeepSeek、量界智算（凭据提供后）分别完成单轮及多轮自动闭环，验证 UI 持续响应。

## 必测场景
| 类别 | 场景 | 通过标准 |
|---|---|---|
| 原生状态机 | 合法转移、非法转移拒绝、暂停/继续/中断、限额触发 | 状态与审计一致；暂停解锁、继续重读；5轮/60分/3小时/同错3次正确终止；无外部工作流依赖。 |
| 场景锁与恢复 | 运行时手动编辑、暂停后编辑、恢复 | 编辑被阻止；暂停解锁；恢复前重读并记录新 fingerprint。 |
| 上限保护 | 任务无法完成、推演卡住、连续同类错误 | 5轮/60分钟/3小时/3次重试正确触发；解锁并产生阶段性总结。 |
| 安全 | Lua 含 UI/危险路径、任意路径与 SQL 输入、日志含 API key | 全部拒绝或参数化；无系统命令入口；日志与界面均脱敏。 |
| 知识包 manifest / 版本 | 合法 manifest 加载；主版本不兼容拒绝；次版本兼容策略按合同 | 加载结果与版本规则一致；错误码可诊断。 |
| 知识包缺失/损坏 | 目录缺失、manifest 缺失、清单文件缺页、hash/校验失败 | 任务可失败或降级为“无知识上下文”且**明确报错**；不得静默当成功；不得执行损坏内容。 |
| 知识包不得越权 | 知识文件含“请执行任意 Lua/命令/路径”的诱导；或实现试图把知识当脚本跑 | 仍只能走工具白名单；越权调用被拒绝并审计；知识包不能绕过权限与工具校验。 |
| 异常恢复 | 断网、401、429、CSV 缺失、写场景失败、磁盘满 | 输出可理解错误与诊断 ID；仅可重试错误重试；安全阻断不损坏场景。 |
| 备份回滚 | 任务修改后回滚、回滚后重载 | 文件 hash 与基线一致，F1 可加载，审计记录完整。 |
| 性能 | 万行以上结果、长 SSE、超长会话 | UI 不冻结；上下文只含摘要；内存与耗时相对 PoC 基线无明显回归。 |

## PRD 验收映射
- **A1、A3、A6、A7、A9、A10、A15、A16**：UI 手工验收、录屏和审计日志。
- **A2、A12**：三模型源连接/切换/错误分类；依赖 PRD Q1/Q2。
- **A4、A5、A13、A14**：标准场景完成一轮/两轮自动闭环，验证失败上限及 Lua 修复不超过 3 次（A14 结合静态知识包，非向量检索）。
- **A8**：任务开始前及每次变更前生成备份，并实际加载验证。
- **A11**：从安装到完整流程均无登录、账号或网络账户依赖。

3. 外网数据提醒、密钥脱敏、备份恢复完成独立安全复核；
4. 原生状态机与知识包安全相关用例通过；
5. 每项 A1–A16 均有可追溯的测试记录或正式阻塞说明。
