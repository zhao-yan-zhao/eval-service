## 二、关键口径

1. **漏发判断** `detectChoiceIntent(text)`：命中四类即强制模型补交卡片——
   - 过去式回执（卡片已发/已发送/已展示）；
   - 方位指向卡片（下方/上面 + 卡片/选项/选择项，如「下方卡片一项」）；
   - 祈使用户选择（请选择/请勾选/请点击/请选中）；
   - 请用户回复序号/数字/字母。
   刻意不收：「已选择方案A」「该方案的选择范围」等过去式/名词性说明。
2. **触发条件** `detectCardRequest(text)`：操作员明确索要卡片（给我/生成/发送/展示…卡片）。
3. **重试上限 2 次**：补交后仍无合法卡片 → SSE 返回 `选择卡片生成失败，请重试。`，不发正文。
4. **卡片先持久化**：回复事件 id 预生成（`newEventId`），卡片按 `sourceEventId` 锚到回复；卡片全部落盘成功后才下发「回复 + claim_check + 卡片」；保存失败则 ai_message 落盘为失败提示，不显示声称有卡片的回复（避免刷新后「有文字无卡片」）。
