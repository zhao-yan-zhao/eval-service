### 2. 三笔欠账（B 项 v1.1 + 流程二遗留）

- **"帮您体"漏网**：`我已为您把想定保存好了` 当前被放行——归因过滤（OTHER_RE 含 您|你）整句跳过所致。修为：仅当"您/你"是**动作主语**时跳过（如"您盘侧已核完"），"我为您/帮你 X 了"句式必须算 AI 自述。补针对性用例；
- **词典斟酌补词**：`结果已出，弹道已算好` 当前放行。可补短语级词条（如 搞定|算好|已出结果），**单字"出"不许加**（误伤面太大）；
- **流程二遗留①**：`db run_sql_script` 纯 SELECT 探查也会消耗一次性改库授权——修为：只读语句（SELECT/PRAGMA 开头，无写入关键字）不消耗授权；**遗留②**：schema 文案 `{rowcount:N}` 与实际 `{rows:...}` 不符，对齐。
