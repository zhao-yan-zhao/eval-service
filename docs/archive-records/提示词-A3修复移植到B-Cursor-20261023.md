## 核心方法（看懂这段再动手）

1. 先跑 `diff A.2版本 A.3版本`，看懂 A 分支这次改了什么、为什么改（A.3 的改动大多带中文注释，注释里写了对应什么 bug 现象）；

   - script 里的逻辑修复可以也基本可以直接对齐；
   - 如果 A 的修复涉及 template 里的交互逻辑（v-if/v-model/事件绑定），把逻辑语义移植到 B 的等价结构上，不要带 A 的 class 名和样式；
