## 一、目标与非目标

**目标**：五天窗口内跑通一条真实、可演示、可复验的推演实验闭环，支撑"奇正"大赛复赛战法开发演示（PPT），并留下可继续开发的工具骨架。

```
战法假设（人+LLM，OKF 知识支撑）
  → 候选想定生成（基准复制 + 审批后的 Lua 变更）
  → 多变体 × 多轮次蒙特卡洛批量推演（进程内、串行、无人值守、GUI 锁定）
  → 数据归一化与指标统计（程序计算，LLM 只解释）
  → LLM 归因解读 → 人批准后进入下一轮迭代
```

**非目标（五天内不做，进 PPT 演进路线页）**：无头独立进程 runner、MCP 服务、OKF RAG 深度接入、无人工审批的全自动闭环、多实例并行跑批、通用平台化。

## 三、关键设计决策（全部有源码实证，行号见预审产物）

### D-1 跑批内核：进程内批量服务，复用无头循环模式

- 模式来源（双先例）：`MonteCarloForm.cs` L500–581（`LoadFromFile`→`GetScenarioObject`→`RunningHeadless=true`→`BranchToNewTimeline`→`MainGameLoop` 至 `HasEnded`→`DestroyPreviousScenario`）；`CmdArgsProccessor.cs` L90–129（命令行 `-R` 无头跑想定）。
- 适配器必须复刻的三行归因赋值：`isMonteCarloRunning=true`、`MonteCarloID=Guid`、`MonteCarloIteration/MonteCarloScn` 逐轮覆写（`MonteCarloForm.cs` L517/L530–535）。
- 适配器**禁止**：弹 `DarkMessageBox`（错误只落日志+标失败，对抗 L577 模态挂死）；引入 `SimServerManager.StartServer`/`LSIPCommon.CurrentRole`（`CmdArgsProccessor.cs` L106/L109，抢端口）；调用 `EventExporterManager.SaveConfig`（覆写用户 ini，L717–767）。
- 进入/退出批模式时对交互想定导出器做对称停/还（复刻 `MonteCarloForm` L433–440 / L632–639）。
- `GameGeneral.Global_PulseResolution` 为进程级静态（L483–494），适配器自行赋值、批后还原。

### D-2 导出配置：全程序化，不信 ini 与默认值

- GUI 模式下 ini 导出开关不生效（`EventExporterManager.cs` L131–141 `RunInCmdMode` 门控）；事件项在 ini 缺键时默认 false（L147–168）。
- 启动批服务时显式调用：`EnableCsvExport(<RunID 独立目录>)`（L1601–1607）+ 事件项开关（WeaponFired/WeaponEndgame/WeaponImpact/UnitDestroyed/Damage/Expenditures/Losses/WeaponLost/ContactPositions/UnitPos/**EngagementCycle**——最后这项默认 false 必须显式开）。
- D1 核查 `DataOutputServer.Running==false`（CSV 写盘同时会向该 TCP 服务广播，`EventExporter_CSV.cs` 约 L246–253）。

### D-3 候选保存链：起跑前保存 + 显式断言 + 哈希钉死

- 用 `LoadSave.SaveScenario`（L29–78），须知三坑：**catch 吞异常**（L69–78，必须保存后显式断言文件存在+回读比对）；`ScenarioDBExport==true` 时弹 InputBox（L51–58，防御性断言该标志为 false）；`SaveCurrentTime` 烙印当前时刻（L48，**必须在 MainGameLoop 起跑前保存**）。
- 保存会改想定当前方（L35–38）与 FileName（L40），回读校验纳入知情。
- 候选 .scen 落盘即算哈希留档；跑批装载前重算比对，不一致拒绝运行（防保存后手工改文件）。

### D-4 Lua 审批链：审批链是唯一防线（内核沙盒无加固）

- 实证：`LuaSandBox.cs` L248–289 沙盒加固 `SecurityString` 两段全部被块注释，本构建 Lua 保留完整 `io`/`os.execute`/`require`/`ScenEdit_RunScript`（L2643–2685 可加载任意路径脚本）/`Exporter_SetSetting`（L1589–1605）。
- 链式流程：**草稿上传 → 静态检查（黑名单+差异预览）→ 人批准三元组哈希（脚本全文+参数 JSON+基准想定哈希）→ 批准后脚本读入内存副本 → 候选副本上执行内存副本 → 保存 → 回读+哈希校验**。
- 静态黑名单：`io.`、`os.execute/remove/rename`、`require/dofile/load/loadstring`、`ScenEdit_RunScript`、`Exporter_SetSetting`、`ScenEdit_UseAttachment`、`ScenEdit_ImportInst`。
- 指标埋点通道（替代被禁的 io）：`ScenEdit_SetKeyValue/GetKeyValue` + `ScenEdit_SetScore/GetScore` + 消息日志。
- 批准到执行之间用内存副本，杜绝"批准后换文件"。

### D-5 状态隔离与随机性

- 实例级隔离成立（每轮 `FromXmlText` 深重建 + `BranchToNewTimeline` 换 Guid + `DestroyPreviousScenario`），静态残留已枚举清零（`oldState`/`isInitPosExported`/`LastEventTime` 每轮重置）。
- 随机性：Lua `math.randomseed(os.time())` + 内核 `VBMath.Rnd()` 静态续播 → 逐轮天然异种子（利好 D1 验收②）、**单轮不可复现** → 每轮落 manifest：RunID、MonteCarloID、TimelineID、候选哈希、参数 JSON 哈希、起止时间戳、F1 构建号、耗时。
- 跑批期 **GUI 锁定**：`isMonteCarloRunning` 期间导出路由全局劫持到 MC 想定（`GetActiveScenario` L1362–1370），"无人值守"升级为"禁止触碰 F1 GUI"。

### D-6 指标层口径

| 指标 | 来源 | 决策 |
|---|---|---|
| 战损 | UnitDestroyed + Losses CSV | 直接 |
| 发射/命中/消耗 | WeaponFired/Endgame/Impact + Expenditures + WeaponLost CSV | 直接 |
| 首次关键事件时间 | 各 CSV Time 列 + SimInfo（MonteCarloID/Iteration/ReferenceTime） | 直接 |
| 交战周期 | EngagementCycle CSV（显式开启） | 直接 |
| 成功率及置信区间 | **自定义 Lua 埋点**（KeyValue/Score，判据随候选一起审批）+ Python 算 CI | 埋点 D2 定稿 |
| 效费比 | Expenditures 计数 × **外部单价映射表**（来源入报告标注） | 单价表 D2 定稿 |
| 初始态势/因子 | `IsExportExperimentEvaluation`（默认 false，按需开启） | D1 与 10 号队 CSV 比对后定 |

CSV 归一化显式登记已知坑：TimelineID 变体、Side/UnitSide 差异、跨目录重复 ID。

## 五、五天排期与硬验收点（每天未达标砍格式/变体数保主链）

| 天 | 交付 | 硬验收点 |
|---|---|---|
| **D1** | 上午尖刺：进程内最小批量循环跑验证想定 ×2 轮 + **保存/回读冒烟**；下午：装备映射表 + 自建基准想定开工 | ①两轮 CSV 各自独立归档（RunID 分目录）；②两轮事件序列不完全相同 + 两轮 SimInfo 的 TimelineID 必不同（Guid，双重排除假随机/假分支）；③第二轮不继承第一轮状态；④**单轮耗时实测**（定矩阵规模上限）；⑤**程序化导出开启生效**（不调对话框、不信 ini）；⑥**无头保存→文件存在断言→回读比对双方单位/任务数通过** |
| **D2** | 候选生成链全通；成功率判据埋点 + 单价表定稿 | 候选 .scen 由审批后 Lua 生成、可回读、基准未覆盖；三元组哈希留档；黑名单命中即拒的负例测试通过 |
| **D3** | 批量执行器 2 候选 × 3 轮跑通；矩阵规模按 D1 耗时定稿；过夜跑批 | 队列/进度/停止/失败记录可用；过夜批完成率与失败原因如实记录（压力测试） |
| **D4** | 统计摘要+图表；LLM 归因报告；**晚：第一次完整彩排** | 每个指标可回溯到原始 CSV 行；图表进 PPT |
| **D5** | 一次真实迭代（改参数→重跑对照组→更新结论）；冻结演示版；第二次彩排；PPT 定稿 | 迭代血缘（假设→参数→结论）完整可查 |
