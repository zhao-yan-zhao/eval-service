## 2. 接口设计（建议，可按源码核查结果调整）

新工具 `unit.set_loadout`（建模档 MODEL，推演中冻结照旧）：

- `unit_id`（必填）+ `mode`（必填枚举）：
  - `clear_magazines`：清空弹舱（包 ClearAllMagazines）；
  - `clear_mounts`：摘除架上武器——**支持过滤**：`weapon_dbid`（单型）或 `weapon_domain`（air_defense/anti_surface/anti_land…按武器主表类型映射，"清空防空导弹"=一句事）；
  - `add_magazine`：`weapon_dbid` + `count`（包 AddWeaponToUnitMagazine）；
  - `set_loadout`：`loadout_id`（飞机整案换装，包 SetLoadout+FillMags）。
- 写后读回对账：返回该单位操作前/后的挂载清单 diff（复用 Q-057 mounts 查询的读取路径），任何一项没生效报 `loadout_no_effect` 并给出哪一项。
- 安全：走 Q-016 同款确认门？**不走**——挂载改动与 unit.add/remove 同级（建模操作），不碰数据库文件。但操作前后 diff 必须入留档（审计行）。
