## A. 帧样本格式（Q-074 产出 → Q-075 输入）

Q-074 的监听器把每帧重组解压后的 JSON 原样落盘，一行一帧（JSONL）：

```jsonl
{"receivedAt":"2026-10-23T01:00:00.000Z","serverId":"s1","scenarioTime":"2026-06-01T04:00:00Z","frame":{ "Scenario": { "...": "引擎原始帧内容，字段不裁剪" } }}
```

- 文件位置：`LabConsole/outputs/bs-frames/frames-<yyyymmdd-HHMMSS>.jsonl`
- `frame` 内是引擎原始结构（`Scenario.Sides / ActiveUnits / NonActiveUnits / GlobalWeather / ...`），监听器不改字段名、不丢字段。
- Q-075 的差分器必须能**离线回放**这种文件（不连 broker 也能开发测试）。

## B. 事件卡格式（Q-075 产出 → Q-076 输入）

差分器逐帧对比后产出事件卡流（JSONL，同样落盘 + 内存队列）：

```json
{
  "eventId": "evt-<ulid>",
  "scenarioTime": "2026-06-01T04:02:31Z",
  "detectedAt": "2026-10-23T01:02:35.000Z",
  "side": "红方",
  "kind": "unit_destroyed | unit_new | weapon_fired | unit_maneuver | detection_new | detection_lost | engine_event | playback_state | parse_error",
  "subject": "单元名或GUID",
  "object": "对象名或GUID，可空",
  "severity": "major | minor",
  "detail": { "原始差异字段": "..." },
  "source": "diff | engine_push"
}
```

- **两档分级就靠 severity**：`unit_destroyed / weapon_fired / detection_new / engine_event(重大) / playback_state / parse_error` → `major`（立即插播）；`unit_maneuver / detection_lost / unit_new(非交战) ` → `minor`（攒批）。
- kind 枚举不够用时可扩，但必须先回本文件登记。
- **登记记录**：`parse_error`（坏帧/字段无法解析的防御卡，major 插播）于 2026-10-23 由监理登记入册——Q-075 v4-pro 首审必修①清偿（Q-075 r2 返修单前置）。
- `engine_event` / `source=engine_push`：帧里引擎自带的事件/触发器/动作推送若能解析，直接用，差分只兜底。

## C. SSE 播报接口（Q-076 产出 → 关的面板小模块消费）

```
GET /api/bs/commentary?taskId=<panelTaskId>
Content-Type: text/event-stream
```

事件两类：

```
event: commentary
data: {"seq":12,"scenarioTime":"...","tier":"major|batch","text":"04:02 红方一枚反舰导弹命中蓝方伯克舰！"}

event: state
data: {"playback":"running|paused|finished|not_running","serverId":"s1","scenarioTime":"..."}
```

- `commentary.tier=major` 为插播，`batch` 为攒批段。
- 心跳：15 秒无内容发 `: ping` 注释行。
- 无播放任务/未 attach 时：先回一条 `state:not_running` 再保持连接。

## D. 播放挂接接口（关的前端在"开始播放"时调用一次，决策 2-1）

```
POST /api/bs/attach
{"serverId":"s1","mqttHost":"127.0.0.1","mqttPort":1883,"taskId":"<panelTaskId>"}
→ 200 {"ok":true} / 400 参数缺 / 409 已挂接别的 serverId（须先 detach）

POST /api/bs/detach  {"taskId":"..."}  → {"ok":true}
```

- proxy 收到 attach 后才启动 MQTT 订阅；detach 或播放结束（victory/exit）自动退订。
- 同一时刻只挂一台引擎（本期范围）。
