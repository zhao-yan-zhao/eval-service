## 0. 你要装出来的东西长这样

```
浏览器 → http://127.0.0.1:8085/        BS 态势主界面（nginx 托管的前端）
                ↓
        Java 后端（hn-deduction，:9205）——想定数据、引擎生命周期管理
                ↓ 拉起
        F1 推演引擎（F1.exe，每个推演实例约 1.1GB 内存）

配套中间件：EMQX（MQTT 推送，:1883/:18083 控制台）+ Redis（:6379）
数据库：SQLite 文件（java/DB/DB3K_508.db3）——**不需要装 MySQL**（配置里已注释掉）
```

五个组件启动顺序：**EMQX → Redis → Java → nginx →（用的时候自动拉起 F1）**。

## 3. 安装步骤（约 30 分钟，含解压）

1. **建目录**：`D:\F1BS-run\`（强烈推荐和 owner 机一致的路径——java 的 SQLite 配置写的是绝对路径
   `D:/F1BS-run/java/DB/DB3K_508.db3`，换路径就要改 `java\config\application.yml` 里这一行）。
2. **解包 1（部署.rar）** 到 `D:\F1BS-run\`。
3. **解包 2（后端 java）** 到 `D:\F1BS-run\`，提示覆盖一律选"是"。
4. **解包 3（nginx）** 到 `D:\F1BS-run\nginx-1.24.0\`。
5. **解包 4（F1 引擎分卷）**：双击 `BS-包4-F1引擎-分卷.part01.rar` 解压到 `D:\F1BS-run\`
   （所有分卷必须在同一目录，解压自动续卷）。
6. **解包 5（想定与脚本）** 到 `D:\F1BS-run\`，覆盖。
7. **装 JDK**：运行 `D:\F1BS-run\jdk-17.0.17_windows-x64_bin.exe` 默认下一步
   （脚本写死调用 `C:\Program Files\Java\jdk-17\bin\java.exe`，别改安装位置）。
8. **启动**：双击 `D:\F1BS-run\start.bat`（目录自适应，按序拉起各组件并等端口就绪）。
9. **验证**：浏览器开 `http://127.0.0.1:8085/` 能看到态势界面即成功。

停止：`D:\F1BS-run\stop.bat`（会连残留 F1.exe 一起收，别漏）。

## 5. 常见坑（都是踩过的）

1. **端口被占**：8085/9205/1883/6379 任何一个被占都会起不来——`netstat -ano | findstr "端口"` 查谁占的。
2. **授权**：F1 是永久授权版，正常不弹授权。**若新机首跑弹授权/注册窗，停下来找 owner**，
   别自己乱点乱拉别的 exe（上次有人拉了旧目录的 exe 导致注册校验失败，查了半天）。
3. **内存**：每个 F1 推演实例约 1.1GB，机器内存 <16GB 别同时开多个。
4. **中文/空格路径**：start.bat 已做目录自适应，放哪都行——除了 java 的 SQLite 路径（见安装步骤 1）。
5. **防火墙首次弹窗**：Windows 问"允许网络访问"一律允许（本机回环通信也要）。
6. **nginx 改配置后**：用 `nginx-1.24.0\2-修改配置重启Nginx.bat`，别直接双击 nginx.exe。
