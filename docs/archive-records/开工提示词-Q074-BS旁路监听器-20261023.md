## 背景实锤（不要重新调研，照做即可）

- BS 引擎（F1-Console.exe）把每帧全量态势发到 MQTT broker（默认 `127.0.0.1:1883`）。
- 主题：`FrameData_${serverId}`（核心帧）、`scenarioTime`、`process_${serverId}`、`victory_${serverId}`、`ReceiveLog_${serverId}`。
- FrameData 分片协议：一帧拆多条消息，每条 JSON 带 `Time / Identifying / Count / Content`；
  按 `Time` 分组收齐 `Count` 条 → 拼接 Content → **Base64 解码 → gunzip → 完整 JSON**
  （`{Scenario:{Time, Sides, ActiveUnits, NonActiveUnits, GlobalWeather, ...}}`）。
- 参考实现：`D:\soft\F1-BS\源码\源码\deduce_code\src\workers\mqtt.worker.js`（172-185 订阅清单、
  约 500-540 行分片重组）。**只读参考，不改它。**

## 交付

1. `demo-ui/proxy/bs-listener.mjs`，导出：
   - `attachBsEngine({ serverId, mqttHost, mqttPort, taskId })` → 连 broker、订主题、开始收帧；
   - `detachBsEngine(taskId)` → 退订断开；
   - `getBsFrame(taskId)` → 最新帧缓存（含 scenarioTime）；
   - `getBsPlaybackState(taskId)` → `running|paused|finished|not_running`（依据 process/victory 主题）；
   - 监听事件回调注册口（Q-076 要用）：`onBsFrame(taskId, cb)`。
2. 帧落盘：每帧一行 JSONL 写 `LabConsole/outputs/bs-frames/frames-<yyyymmdd-HHMMSS>.jsonl`，
   格式**严格按**《接口约定-BS播报-20261023.md》§A。
3. 依赖：`npm i mqtt pako`（写进 package.json dependencies）。若环境离线装不上，换
   `node:net` 手写最小 MQTT 客户端也行不通就停工报告，别硬凑。
4. server.mjs 挂两行路由（仅此两处改动允许碰 server.mjs）：

5. 测试 `proxy/bs-listener.test.mjs`：

   - attach/detach 幂等、双 attach 409；
