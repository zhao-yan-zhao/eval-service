1. **单槽起停（槽 1）**：用 `slot_supervisor.py` 拉起 slot-01 → 断言：F1.exe 进程起来、令牌注入零落盘、桥在 **9478** 应答（无令牌 401 即可）、加载锚点想定 `测试.scen`（槽内数据根副本）→ 发 stop → 断言：WM_CLOSE → "你确定吗？"确认框被 BM_CLICK 应答 → 进程 exit 0、无残留、无悬窗。

3. **双槽并发**：slot-01 + slot-02 同时拉起，各自桥端口各自应答、互不串（槽 1 的想定操作不出现在槽 2）；然后分别 stop 干净。
4. **与生产共存**：双槽运行期间，生产 9477 的健康检查仍正常（不启动、不停生产实例，只探活）。
5. **异常路径**：对运行中的槽再发一次 start（应端口互斥拒绝）；stop 一个已停的槽（应幂等不报错）。
6. 全程磁盘、内存占用记录（双槽并发时的峰值，供阶段 3 容量规划）。
