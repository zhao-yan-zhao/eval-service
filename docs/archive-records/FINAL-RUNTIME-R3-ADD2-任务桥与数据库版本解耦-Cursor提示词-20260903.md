后续飞机测试若要用 515，正确动作是加载已经准备好的 515 工作想定，而不是把当前 505 想定临时迁移成 515。该后续步骤另行处理。

- 仍显示“任务控制尚未接入运行时”；
- 日志为 `enabled=False`；
- 再次出现 `recover_on_startup_failed` 或 `runtime_schema_unsupported:1`；

若失败，只读收日志并报告，不得让 owner 改数据库、删 assistant.db/wal/shm 或反复重启。
