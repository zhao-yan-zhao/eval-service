## 任务

新增 `demo-ui/proxy/bs-commentary.mjs` + server.mjs 挂一条路由：

```
事件卡流（内存队列）→ 两档分级 → LLM 概括 → SSE 推到面板
```

owner 拍板的三件事：SSE 推送；serverId 由面板 attach 时传入（Q-074 已实现路由，本单只对接）；
**两档播报**——major 立即插播、minor 攒批。

## 管线规格

1. **事件入口**：`pushBsEvent(taskId, eventCard)`（Q-074/Q-075 联调时由监听器+差分器喂进来；
   本单测试用手推 mock 事件）。
2. **两档**：
   - `severity=major` → 立即单条送 LLM 概括（提示词模板：足球解说员口吻，1-2 句人话，
     必须带场景时间戳 HH:mm:ss，不编造事件卡里没有的信息）；
   - `severity=minor` → 攒批：每 12 秒或攒满 8 条（先到先触发）合成一段（1-3 句）；
   - LLM 调用走既有 `provider.mjs` 的 `resolveSendRoute({stage:4})`（段4=deepseek-flash），
     不许新写 provider 逻辑；LLM 超时/失败 → 把事件卡原文降级直发（tier 标 `raw`），不丢事。
3. **SSE 接口**：`GET /api/bs/commentary?taskId=...`，消息格式严格按约定 §C
   （`commentary` / `state` 两类 + 15s 心跳 `: ping` + 未 attach 先发 `state:not_running`）。
4. **播报落盘**：每条 commentary 追加 `LabConsole/outputs/bs-frames/commentary-<日期>.jsonl`
   （含 seq/tier/text/源事件 eventId 列表），可回放对账。
5. 测试 `proxy/bs-commentary.test.mjs`：mock LLM（拦截 fetch）+ mock 事件源——
   验证 major 立即发、minor 攒批窗口、LLM 失败降级、SSE 帧格式、心跳、多 taskId 隔离；
   挂 `test:all` 末尾。
