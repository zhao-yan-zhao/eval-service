## 2. 部署步骤（前端包同步）

源：`D:\soft\F1-BS\deduce_code_ui2\deduce_code_build\`（Windows 侧构建产物，已是最终 B.2 版）
目标：`D:\soft\F1-BS\Linux安装\resources\html\`（麒麟离线安装包的前端目录）

### ⚠️ 第一步必须做：清旧 chunk（不做会塞进一堆废文件）

Windows 侧构建目录 `deduce_code_build\assets\` 里**堆了 30 个历史版本的 index.*.js**（构建没开自动清空）。当前 index.html 只引用 `index.bcc5455b.js`（其余 29 个全是垃圾）。同理 assets 下其他 hash 文件也有历史堆积。

**正确做法（二选一）：**

a) **推荐·干净同步**：
```bash
# 1. 清空目标 html 目录（里面的东西全部由构建产物重新提供）
rm -rf /d/soft/F1-BS/Linux安装/resources/html/*
# 2. 全量拷贝当前构建产物
cp -r /d/soft/F1-BS/deduce_code_ui2/deduce_code_build/* /d/soft/F1-BS/Linux安装/resources/html/
```
注意：先确认 `deduce_code_build` 里 config.js / mapList / table / models 等运行时目录齐全（它们不是每次构建都重新生成，是从 public 拷的——本次构建已包含，直接整目录拷即可）。

b) 保守做法：只拷贝 `index.html` 实际引用的文件——不推荐，容易漏。

**核对**：同步后 `resources/html/index.html` 里引用的每个 hash 文件都必须真实存在于 assets/ 里。

### 第二步：重算 SHA256SUMS

```bash
cd /d/soft/F1-BS/Linux安装
# html 下所有文件重算哈希并更新进 SHA256SUMS.txt（保持原有格式：<64位哈希>␣␣<相对路径>）
```
原有格式参考：文件开头几行是 `offline/docker-29.8.1.tgz` 等离线资源，html 相关条目在对应区段。**只更新 html/ 下的条目，offline/ 等其他行一行不动。**

### 第三步：麒麟侧部署

走安装包自带的 `deploy.sh`（幂等，可重复执行；职责边界见脚本头注释：人工上传离线资源到 /data/offline/ + 部署后人工校对业务参数，中间过程脚本全包）。前端是 nginx 容器直接托管 resources/html，同步完重启 nginx 容器或整跑 deploy.sh 均可。

## 3. 测试协助清单（协助 owner 走查）

### A. 麒麟特有检查项（Windows 上验不了，必须在真机看）

1. **字体**：界面英文数字设计用 Calibri（微软字体，麒麟没有，会回退系统字体）。打开任意弹窗看英文/数字显示是否体面；如果明显难看，回报监理换跨平台字体
2. **地图流畅度**：Cesium 吃 GPU。麒麟 ARM 机上拖拽/缩放地图，看是否卡到不可用；如果卡，记录显卡型号和浏览器版本回报
3. **浏览器**：记录麒麟上实际用的浏览器及版本（Chromium 内核版本太老可能不兼容 ES 新语法，若白屏按 F12 把 Console 红字截图回报）

## 4. 后端兼容性注意（重要）

B.2 前端新增了对两个 HTTP 接口的调用：

- `POST /deduction/datasource/switch`（切换数据库时给会话绑数据源）
- 数据源信息查询（getDataSource）

**这两个接口是 A 分支后端的新接口，麒麟环境的后端不一定有。** 前端已做降级设计（silent 请求）：后端没有时**只在界面顶部弹一条 warning 提示、console 有报错日志，功能不中断、不重复弹窗**。走查第 8 项时如果看到"后端数据源绑定失败"的警告——先确认后端版本；引擎侧切库（WebSocket 链路）不受影响仍生效。要彻底支持需后端补接口（已登记在技术债备忘，owner 知情）。

## 5. "别当 bug"清单（测试时看到这些是正常的）

1. 加载动画一直转不停 = 引擎 WebSocket 没连上（后端服务没起全），不是动画卡死
2. 单元详情没有"推进系统" = owner 决策删了（后端接口没了，留着只有空表）
3. 选择想定没有"导出"按钮 = owner 决策删了（语义名不副实）
4. 新增分方默认中立 = owner 拍板的口径（与 A 分支的"默认全敌对"不同，以 B 分支为准）
5. 切数据库时弹一条 warning = 第 4 节的后端接口问题，不阻断
6. 构建时 HudToolDock.vue 有一条 CSS 选择器警告 = 既有问题，不影响运行
7. "范围标识"弹窗代码在但界面没入口 = 刻意不接线（孤儿组件，owner 拍板）
