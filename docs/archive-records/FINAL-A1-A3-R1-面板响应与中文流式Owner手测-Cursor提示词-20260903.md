# FINAL-A1-A3-R1：面板响应与中文流式 Owner 手测

## 一、本轮测试什么

本轮同时验证两个用户可见功能：

1. **A1 面板响应**：AI 回复期间，F1 主地图仍能点击、拖动，不能整窗卡死。
2. **A3 中文流式**：回复应逐步出现，而不是长时间无反应后一次性全部弹出；中文不能乱码，面板不能花屏。

本轮只发普通聊天，不创建任务、不调用工具、不修改想定。

## 二、Cursor 禁止事项

- 禁止控制鼠标、键盘、窗口。
- 禁止点击 F1 或 AI 助手的任何按钮。
- 禁止读取或展示 API Key。
- 禁止修改配置、数据库、源码、想定或验收矩阵。
- 只旁观 owner 截图，并只读收集本轮模型/流式日志。

## 三、Owner 唯一操作

1. 保持当前想定暂停；不要保存想定。
2. 打开 AI 助手。
3. 点击 AI 面板**最下面的普通聊天输入框**，粘贴以下文字：

```text
这是界面流式显示测试。不要调用任何工具，不要创建或执行任务，不要读取或修改当前想定。请直接用中文写一篇约400字的说明，分成8个编号段落，主题是“如何判断一架飞机正在按规划航线正常飞行”。每段至少两句话，正常回答即可。
```

4. 点击输入框右侧的 **“发送”**。注意：不是上方任务区的“执行任务”。
5. 回复生成过程中，观察文字是否一段段逐步出现；同时尝试拖动 AI 面板一下，并在主地图空白处单击一次。
6. 回复完成后截一张完整 AI 面板图，并告诉监理三件事：
   - 文字是逐步出现，还是最后一次性出现；
   - 中文有没有乱码；
   - 回复期间地图点击、窗口拖动是否正常。

## 四、通过标准

- 回复是逐步显示；
- 中文无乱码；
- AI 面板无花屏/崩溃；
- 回复期间 F1 主界面仍有响应。

任一项不符合就如实截图停手，不重试、不换模型。
