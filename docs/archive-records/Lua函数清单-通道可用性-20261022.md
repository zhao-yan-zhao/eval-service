# Lua 函数通道可用性清单（2026-10-22）

**口径**：以槽位现役 `F1Lua/assets/Functions.html`（130 个 ScenEdit_* 函数）为基准，逐一对照引擎沙箱（LuaSandBox.cs 注册表）与桥通道现状。

## 一句话结论

**引擎层一个不拦——Functions.html 里 130 个函数在沙箱里全部注册在案，外加 16 个文档没列的隐藏函数也可用。唯一的闸门在桥：`F1_AI_LUA_OPEN` 没开，lua.exec 不在工具白名单，AI 的脚本根本递不进引擎。**

三层闸门明细：

| 层 | 拦什么 | 不拦什么 |
|---|---|---|
| 引擎沙箱封锁段（LuaSandBox.cs:52-87） | dofile / io / os.execute / os.exit / require / loadstring / debug.* / CLR 互操作等 Lua 标准库危险面 | **任何 ScenEdit_* 函数都不拦** |
| 桥脚本安检器（LuaScriptSecurityScanner，R01-R23） | 同上黑名单 + 方括号动态调用 + AddUnit 字段校验 | 不拦任何 ScenEdit_* 函数 |
| 桥工具白名单 | **lua.exec 整个工具没开（env F1_AI_LUA_OPEN 未置）→ 这是 AI 昨天"通道被拒"的全部原因** | template.execute 六个白名单模板照常 |

## 分类清单

### A 类：现在就能用（已被语义工具/模板封装，无需 lua.exec）

| 能力 | 现通道 |
|---|---|
| 建/改/查单位、删单位 | unit.add / unit.update / unit.status / unit.delete |
| 挂载增删（编译波4已部署） | unit.set_loadout（含回填） |
| 想定装载/另存/列表/设时间 | scenario.load / save / list / set_time |
| 参考点增 | referencepoint.add（模板） |
| 条令/WRA | doctrine.set_wra / doctrine.set |
| 事件（六种动作含 spawn_units） | event.upsert（模板白名单） |
| 库查询 | db3k.search / detail / relations |
| 推演控制/状态/产物 | simulation.run / stop / status、result.* |
| 接触查询 | contact.query |

### B 类：引擎已注册、桥一开就能用（130 个全在此类，重点列高价值）

| 函数 | 干什么 | 价值 |

| ScenEdit_SetStartTime | 改起始时刻 | 治"昼间设置不生效"的备选路径 |
| ScenEdit_SetUnit | 改单元全参数 | 比 unit.update 面宽 |
| ScenEdit_SetMission / AddMission | 任务全参 | 现只封装了增删改挂 |

### C 类：引擎能用但 AI 禁用/慎用（UI 交互类，会卡 UI 线程诱发 Q-063 式卡死）

| 函数 | 风险 |
|---|---|
| ScenEdit_InputBox / ScenEdit_MsgBox | 弹模态框等人工——AI 局里=自杀 |
| ScenEdit_PlaySound / PlayVideo | 弹播放器 |
| ScenEdit_SelectedUnits | 读的是人工在界面里的选择，AI 场景无意义 |
| ScenEdit_RunScript | 脚本套脚本，绕安检器，禁 |
| ScenEdit_ImportScenarioFromXML / ExportScenarioToXML | 直接读写文件，走授权根外的路径风险 |

建议：lua.exec 开放时，安检器对 C 类加黑名单（面板 AI 身份下拒用）。

### D 类：引擎/stdlib 级封锁（不是 ScenEdit 函数，列出备查）

dofile、io.*、os.execute/exit/getenv/remove/rename/tmpname、require、load/loadstring/loadfile、package.*、debug.*、rawget/rawset/rawequal、newproxy、luanet/import/load_assembly、string.dump、module。

### 隐藏可用（文档没列但沙箱注册了，16 个）

ScenEdit_AddAircraft / AddShip / AddSubmarine / AddFacility（AddUnit 的分类型快捷版）、ScenEdit_AttackContact_Immediately、ScenEdit_ClearAllMagazines、ScenEdit_CreateFlightPlans / UpdateFlightPlans（航线计划！）、ScenEdit_GetFormation、ScenEdit_GetKeyStore、ScenEdit_IsUnitInZone、ScenEdit_LoadComplate、ScenEdit_SetLoadoutAvailable、ScenEdit_TransferMount、ScenEdit_UpdateEvent、ScenEdit_UpdateRSetting。
