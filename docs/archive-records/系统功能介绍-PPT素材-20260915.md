## 0. 一句话定位与系统全景

**定位**：一套「AI 驱动兵棋推演实验」的全自动流水线系统——以 F1 商业级兵棋推演程序为仿真内核，通过自研桥接层把推演程序变成 AI 可编程的实验设备，实现**想定自动生成→自动装载→自动推演→事件数据自动落盘→指标自动判读→报告自动生成**的零人工闭环，并由多 AI 协同工作流持续开发、监控、维护该系统自身。

**系统五大子系统**：
1. **F1 推演桥（AiAssistantBridge）**——推演程序的 AI 可编程接口 ✅
2. **想定工厂与蒙特卡洛实验框架**——声明式想定生成与批量实验 🔧（主链已通，性能优化在修）
3. **指标判读与报告流水线**——从原始事件数据到一页纸结论 ✅
4. **LabConsole 开发控制台 + 多 AI 协同工作流**——系统自身的开发运维体系 ✅
5. **监控告警与定时任务体系**——7×24 无人值守运行保障 ✅

## 1. F1 推演桥（AiAssistantBridge）✅

把交互式 GUI 兵棋程序变成进程外可编程设备的核心组件（C#，进程内宿主）。

### 1.1 通道与安保
- **HTTP 桥**：F1 进程内挂 `HttpListener`，仅绑定 `127.0.0.1:9477`，不接受任何外部连接 ✅
- **Bearer Token 鉴权**：启动脚本注入环境变量，无 token 一律 401；鉴权先于路由 ✅
- **工具白名单**：19 个结构化工具，未登记工具一律拒绝 ✅
- **全量审计哈希链**：每次调用落审计日志，步骤间哈希串联（ai_sessions/ai_tasks/ai_task_steps 三级 FK），篡改可检出 ✅
- **高风险闸**：mutating 类工具走 inflight 哨兵+授权根检查，业务拒绝 fail-closed ✅
- **停止阶梯（Stop Ladder）**：推演停止走 取消→快照→Pause→导出 drain→确认 五步；停止未确认时 `edit_blocked` 阻断一切编辑，防止脏状态 ✅
- **有界封送**：一切 UI 线程封送带 10 秒超时（BF-02），桥永不再被拖死——推演繁忙时返回 `ui_marshal_timeout` 优雅报错而非挂死 ✅（K105 真机实证）

### 1.2 工具清单（19 个，全桥真机验证过）
| 域 | 工具 | 能力 |
|---|---|---|
| 想定 | scenario.get_summary / load / save / set_time | 读摘要（阵营/单位数/时长）、装载、保存（含 saveAs 另存候选，原想定哈希不变 LAB-10）、设开局时刻 |
| 单位 | unit.add / update_position / status | 加单位（DBID+载荷+航线；Facility 地面设施已解禁 LAB-11）、改位置、查状态 |
| 任务 | mission.create_or_update | 打击/巡逻等任务创建与参数更新 |
| 条令 | doctrine.set | 阵营/单位级武器使用授权（WCS）等 🔧（生效链 BF-03 修复待派） |
| 触发器 | event.upsert | time / unit_destroyed 两类触发+动作 🔧（同上） |
| 模板 | template.execute | **审核模板执行通道（LAB-B2）**：过静态安检+哈希登记的 Lua 建场脚本以"模板"身份执行——登记哈希不符即拒（template_digest_mismatch 实证），是结构化工具表达不了的复杂建场内容（任务/触发器/KeyValue 埋点）的合规通道 ✅ |
| 仿真 | simulation.run / stop / status | 脉冲驱动推演（duration_pulses 精确控制）、停止、状态查询（双层信封 JSON） |
| 数据 | result.read | 终局结果读取（Succeeded 才开放） |
| 感知 | contact.query / unit.status / referencepoint.list / area.query | 接触/单位/参考点/区域查询 |
| 装备库 | db3k.search | DB3K 装备数据库检索（机型/载荷/武器清单） |

- **桥状态驱动完局判据**（MC-BATCH-FIX-01，a859032a）：轮询 simulation.status 至终局相位，Succeeded→尾量落盘→归档；Failed 如实判败不掩盖 ✅

- 粗筛 20 局/场景、细筛 50 局/场景的批次定义 ✅

### 4.3 统计与评估
- **csvkit 通用 CSV 处理包**（CSV-01）：清洗/统计/航迹/联表四脚本+31 表清点文档（含四大联查配方）✅——实证产出：AIM-9M 命中率 33.3%、GBU-24 48.0%、红方存活率 60.5% 等真实判读数字
