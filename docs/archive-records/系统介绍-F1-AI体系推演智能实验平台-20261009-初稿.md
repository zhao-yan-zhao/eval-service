# 体系推演智能实验平台（F1-AI）介绍

## 一、概述

体系推演智能实验平台（简称 F1-AI 平台）是在成熟的专业推演系统（F1）之上构建的人工智能应用平台。平台将人工智能大模型的理解、规划与生成能力，与专业推演系统的仿真计算能力连接起来，使研究人员能够用自然语言下达任务，由人工智能自动完成从实验设计、想定构建、推演运行到统计分析的全部流程，最终产出可供决策参考的量化评估结论。

平台的核心价值在于把一次完整仿真实验的周期从"以天计的人工操作"压缩到"以小时计的自动运行"，并且保证每一步操作规范、可复查、可复现。

## 二、建设背景

体系对抗方案的评估验证，传统上依赖研究人员在推演系统中手工构建想定、逐次运行、人工汇总结果。这一方式存在三方面局限：一是想定构建工作量大、周期长，难以支撑多方案快速比较；二是人工操作的一致性难以保证，批量实验的结果可比性不足；三是推演系统功能复杂，使用门槛高，熟练人员培养周期长。

与此同时，人工智能大模型在需求理解、方案规划、文档生成等方面已表现出较强能力，但大模型本身不具备直接、安全地操作专业推演系统的手段。本平台的建设目标，正是解决人工智能能力与专业推演工具之间"安全连接、规范使用、全程留痕"的问题。

## 三、系统组成

平台由四个层次组成：

**（一）推演引擎层。** 即 F1 推演系统本体，负责仿真计算。平台对引擎本体的修改极少（仅三处配合性小改动），全部新增能力以独立功能模块的方式叠加，不影响引擎原有功能与稳定性。

**（二）智能接口层。** 将推演系统的装载想定、部署单位、设置任务与交战规则、运行推演、读取结果等功能，封装为一组受控的标准操作接口。人工智能的一切操作都经由该层进行，接口具备身份鉴权、操作白名单、调用审计等安全措施，且仅允许本机访问，不对外开放网络连接。

**（三）知识与规程层。** 包括两部分：一是任务规程库，把每类任务（实验设计、想定构建、批量实验、数据库修改）的操作流程、质量标准和禁止事项写成规范文件，人工智能执行任务前必须研读并遵守；二是战例知识库，收录两千余篇实战案例与研究文献，作为方案设计的依据来源，防止人工智能凭空编造。

**（四）应用层。** 面向用户的网页控制台和配套工具集。控制台按实验流程分为四个部分：构想澄清、实验设计、想定生成与推演、统计分析，各部分均可通过对话方式与人工智能交互。

## 四、核心功能

**（一）需求理解与实验设计。** 研究人员以自然语言描述研究设想，人工智能依据战例知识库对设想进行澄清和补全，形成包含实验目的、变量设置、对照方案、合格判据的实验设计文档。合格判据先于想定构建确定，避免"先出结果后定标准"的逆向论证。

**（二）想定自动构建。** 人工智能依据实验设计文档，在推演系统中自动完成单位部署、任务分配、交战规则设置、触发条件配置等工作，生成候选想定文件。构建过程遵循"先行判据、小步验证、抽样复核"的规程：先小规模试运行确认想定合理，再批量生成；批量生成后按比例抽样检查，发现同类问题统一返修。

**（三）推演自动运行与数据采集。** 想定按设定时长自动运行，运行过程中的单位位置、武器发射、命中、损伤、沉没等事件全部自动记录为数据文件。数据采集以文件落盘为准，运行期间不对系统进行干预性查询，保证推演过程稳定。

**（四）批量重复实验与统计分析。** 平台支持蒙特卡洛式批量实验，即对同一想定进行数十次重复运行，或对变量矩阵中的多个方案批量运行，自动完成数据清洗、指标计算、置信区间统计和批次报告生成。统计结论严格以落盘数据为唯一依据，并设置多重质量闸门：试跑不合格的想定不进入正式批跑；终态不明的局次一律按失败处理；批量结果必须经过抽样复核方可采信。

**（五）装备数据库的规范化管理。** 推演所用的装备数据库与想定强关联，一旦修改不当会导致引用该库的全部想定失效。平台为此设立了完整的管理机制：任何修改必须经操作员明确批准；正式库只允许复制副本后修改，禁止直接改动原件；每次修改自动记录前后校验值并留档；修改后小步验证，发现异常立即回退。全部操作留有审计记录，可追溯每一次修改的责任人、时间、内容和依据。

**（六）网页控制台。** 控制台以图形界面呈现上述实验流程，流程进展逐段点亮，各阶段人工智能的输出与依据直观可见。控制台同时支持演示模式，可按预设剧本回放完整实验过程，用于成果汇报与教学演示。

## 五、安全与可靠性设计

平台在设计中贯彻"权限最小化、高风险动作必须人工确认、全程留痕"的原则，主要包括：

1. **接口安全**：智能接口仅监听本机地址，外部网络无法访问；所有调用须持有效凭证；接口能力按白名单逐项开放。
2. **人工确认机制**：数据库修改等高风险操作不设界面按钮，须由操作员在对话中了解风险、明确确认后方可执行，确认内容原文留档。
3. **运行护栏**：推演运行期间自动冻结可能干扰系统稳定的操作，防止误操作导致仿真中断。
4. **副本与回退**：数据库修改一律在副本上进行，修改前自动备份，异常可即刻恢复。
5. **审计留痕**：操作日志、实验数据、评估报告全部落盘保存，数字结论以落盘文件为唯一依据，不接受口头转述。

## 六、应用验证情况

平台已完成功能验证与多轮实际应用，主要包括：

- 完成某对抗场景的想定自动生成与批量重复实验全流程验证，覆盖想定构建、批量运行、统计分析、评估报告各环节；
- 完成某型无人作战飞机武器改装的数据库修改与对抗效果对比测试，从问题定位、数据库修改到效果验证形成完整闭环；
- 平台自身的软件研制过程采用了多人工智能协同的开发模式，任务派发、代码编写、独立审查、进度看板全程留痕，该模式本身亦构成平台能力的一部分。

## 七、小结

F1-AI 平台实现了人工智能与专业推演系统的安全连接和规范化协同，使体系对抗实验具备了"自然语言驱动、全流程自动、结论可复核"的能力。平台各组成部分均经过实际验证，具备进一步扩展任务类型、深化交互体验、支撑更多研究方向的良好基础。
